# Not The Hidden Wiki

## Note Taking Tools
-----

-  AppFlowy: The Open Source Alternative To Notion. Supports macOS, Windows & Linux - [link](https://appflowy.io)
-  QOwnNotes: Open source plain-text file markdown note-taking native-application with Nextcloud / ownCloud integration - [link](https://qownnotes.org)
-  Cherrytree: A hierarchical note-taking app, featuring rich text and syntax highlighting - [link](https://giuspen.com/cherrytree)
-  TreeSheets: Free Form Data Organizer using hierarchical spreadsheet - [link](https://strlen.com/treesheets)
-  Zim Desktop Wiki: Open source multi-platform native desktop GUI to manage a collection of local wiki pages - [link](https://zim-wiki.org)
-  Tomboy: GNOME desktop note-taking application for Linux, Windows, and macOS - [link](https://wiki.gnome.org/Apps/Tomboy)
-  nvpy: Open source cross-platform Simplenote syncing Notational Velocity and ResophNotes inspired note-taker - [link](https://github.com/cpbotha/nvpy)
-   Red Notebook: Open source native desktop journal using plain-text files - [link](https://rednotebook.sourceforge.io)
-   GitJournal: Open source markdown notes editor with integrated syncing with Git - [link](https://gitjournal.io)
-  Fluster: All in one note taking solution for modern students and academics. Powered by Rust with integrated AI - [link](https://fluster.app)
-  zk: A command-line tool helping you to maintain a plain text Zettelkasten or personal wiki - [link](https://github.com/mickael-menu/zk)
-  nb: A command line and local web note‑taking, bookmarking, archiving, and knowledge base application - [link](https://xwmx.github.io/nb)
-  Logseq: Local-first, non-linear, outliner notebook for organizing and sharing your personal knowledge base - [link](https://logseq.com)
-  SiYuan: A privacy-first, self-hosted, fully open source personal knowledge management software - [link](https://b3log.org/siyuan/en)
-  TriliumNext Notes: A cross-platform personal knowledge base with advanced features. WYSIWYG - [link](https://github.com/TriliumNext/Notes)
-  Zettlr: Markdown Editor for the 21st century - [link](https://zettlr.com)
-  Standard Notes: A free, open-source, and completely encrypted notes app - [link](https://standardnotes.com)
-  AnyType: Open source local-first electron and phone app for tasks, notes, and more - [link](https://anytype.io)
-  Bangle.io: A free alternative to Notion that takes markdown notes saved right in your computer - [link](https://bangle.io)
-  Linked: Forget less by daily journaling, completely offline, secure and free - [link](https://uselinked.com)
-  Calculist: The open source thinking tool for problem solvers - [link](https://calculist.io)
-  TidGi: Customizable personal knowledge-base with git as backup manager and blogging platform - [link](https://github.com/tiddly-gittly/TidGi-Desktop)
-  AFFiNE: Next-gen knowledge base that brings planning, sorting and creating all together - [link](https://affine.pro)
-  Joplin: Open source note taking app that supports synchronization and has Windows, Linux, Android, Cli builds - [link](https://joplinapp.org)
-  CodiMD: CodiMD is the free software version of HackMD with reduced features - [link](https://github.com/hackmdio/codimd)
-  Hypothes.is: Annotate anything online - [link](https://web.hypothes.is)
-  Fossil: Source control software with built-in stand-alone wiki pages - [link](https://fossil-scm.org)
-  SilverBullet: Free, open-source self-hosted PWA for markdown notes - [link](https://silverbullet.md)
-  Obsidian: Free for personal use app, that works on top of a local folder of plain text Markdown files - [link](https://obsidian.md)
-  Wridea: Web service to organize and improve ideas and notes by sharing with friends and necessary tools - [link](https://wridea.com)
-  Google Keep: Google Keep is a note-taking service developed by Google - [link](https://keep.google.com)
-  OneNote: Microsoft OneNote is a program for free-form information gathering and multi-user collaboration - [link](https://onenote.com)
-  Simplenote: Available for iOS, Android, macOS, Windows, Linux, and the web and supports Markdown - [link](https://simplenote.com)
-  Squid: Android app to take digital handwritten notes for class, work, or fun! Markup PDFs and sign documents - [link](https://www.squidnotes.com)
-  HackMD: HackMD helps developers write better documents and build active communities with open collaboration - [link](https://hackmd.io)
-  Evernote: An (online) app designed for note-taking, organizing, task management, and archiving - [link](https://evernote.com)
-  Inkdrop: An (online) app for organizing Markdown notes - [link](https://inkdrop.app)
-  Workflowy: WorkFlowy is a web-based organizational tool to create todo lists, notes, team projects and others - [link](https://workflowy.com)
-  DEVONthink: macOS or iPhone app with lots of features that can handle many files - [link](https://devontechnologies.com/apps/devonthink)
-  Roam: A note-taking tool for networked thought - [link](https://roamresearch.com)
-  TheBrain: Mind mapping and personal knowledge base software application - [link](https://thebrain.com)
-  Supernotes: A multi-platform notes app built around markdown notecards and card nesting - [link](https://supernotes.app)
-  NotePlan: NotePlan combines tasks, notes, and calendar - all in one place - [link](https://noteplan.co)
-  Taskade: A tree-structured note-taking and productivity app for individuals and teams - [link](https://taskade.com)
