# Not The Hidden Wiki

## Speaker Tools
-----

1. Google Slides: Create, edit, collaborate, and present wherever you are - [link](https://docs.google.com/presentation)
2. Marp: Markdown Presentation Ecosystem for creating beautiful slide decks - [link](https://marp.app)
3. MDX-Deck: Award-winning React MDX-based presentation decks - [link](https://github.com/jxnblk/mdx-deck)
4. patat: Presentations Atop The ANSI Terminal - show presentations using only terminal - [link](https://github.com/jaspervdj/patat)
5. RevealJS: A framework for easily creating beautiful presentations using HTML - [link](https://revealjs.com)
6. Slides.com: A suite of modern presentation tools, available right from your browser - [link](https://slides.com)
7. Slidev: Presentation Slides for Developers - [link](https://sli.dev)
8.  Spectacle: A React.js based library for creating presentations using JSX syntax - [link](https://github.com/FormidableLabs/spectacle)
9.  Asciinema: Record terminal sessions and sharing them on the web without screen capture - [link](https://asciinema.org)
10. Carbon: Create and share beautiful images of your source code - [link](https://carbon.now.sh)
11. Code Surfer: React component for scrolling, zooming and highlighting code - [link](https://github.com/pomber/code-surfer)
12. Terminalizer: Record your terminal and generate animated gif images or share a web player - [link](https://terminalizer.com)
13. ttygif: Convert terminal recordings to animated gifs - [link](https://github.com/icholy/ttygif)
14. SlidesCodeHighlighter: Highlight your code and paste everywhere - [link](https://romannurik.github.io/SlidesCodeHighlighter)
15. Binder: Transform a github repository into a set of interactive Jupyter Notebooks - [link](https://mybinder.org)
16. Chrome Canvas: A simple white canvas...free your imagination - [link](https://canvas.apps.chrome)
17. Photopea: Advanced and free online photo editor - [link](https://photopea.com)
18. Loom: Capture your screen, voice, and face and instantly share your video - [link](https://loom.com)
19. Krisp: Mute background noise in any communication app - [link](https://krisp.ai)
20. Mermaid: Create diagrams and visualizations using text and code - [link](https://mermaid-js.github.io/mermaid)
21. Claper: The ultimate tool to interact with your audience. An open-source alternative to Slido, AhaSlides and Mentimeter - [link](https://claper.co)
22. PaperCall: PaperCall enables event organizers and speakers to easily manage their call for papers - [link](https://papercall.io)
23. Sli.do: Empower your audience to ask questions, vote in polls and be a part of the discussion - [link](https://slido.com)
24. SlideServe: Upload and Share Presentations Online - [link](https://slideserve.com)
25. SlideShare: Share what you know and love through presentations, infographics, documents and more - [link](https://slideshare.net)
26. Streamyard: The easiest way to create professional live streams - [link](https://streamyard.com)
27. Zoom.us: Enterprise video conferencing with real-time messaging and content sharing - [link](https://zoom.us)
28. GoToMeeting: Seamless video meetings with up to 250 participants - [link](https://gotomeeting.com)
