# 🧑‍💼 Not The Hidden Employees

## 🔄 Matching process

1. **Employer** sends inquiry with profile numbers
2. **Administrator** verifies the inquiry
3. **Candidates** receive information about interest
4. **Candidate** decides about sharing contact details
5. **Direct contact** between parties (outside the system)
