# Not The Hidden Wiki

## IaC
-----

-  tfsec is a static analysis tool that scans Terraform code for security vulnerabilities and misconfigurations​ - [link](https://github.com/aquasecurity/tfsec)
-  Snyk that detects, tracks, and alerts on infrastructure drift - [link](https://github.com/snyk/driftctl)
-  Checov it scans cloud infrastructure configurations to detect security and compliance misconfigurations - [link](https://github.com/bridgecrewio/checkov)
-  Terrascan IaC to mitigate risk before provisioning cloud-native infrastructure. It supports frameworks:Terraform, AWS CloudFormation, and Kubernetes - [link](https://github.com/tenable/terrascan)
-  Terraform compliance a lightweight, security and compliance focused test framework against terraform to enable negative testing capability - [link](https://github.com/terraform-compliance/cli)
-  Ansible Collection that provides comprehensive security hardening for many Linux operating systems, MySQL, Nginx, and OpenSSH - [link](https://github.com/dev-sec/ansible-collection-hardening)
