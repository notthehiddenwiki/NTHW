# Not The Hidden Wiki

## Learn SAST
-----

-  Binskim a binary static analysis tool that validates that Windows portable executables (PE) and Linux ELF binaries comply with security best practices and standards - [link](https://github.com/microsoft/binskim)
-  SonarQube platform for continuous inspection of code quality. It performs automatic reviews to detect bugs, code smells, and security vulnerabilities in code - [link](https://github.com/SonarSource/sonarqube)
-  Semgrep static analysis tool that combines the speed and flexibility of grep with the syntax awareness of traditional static analysis tools - [ink](https://github.com/semgrep/semgrep)
-  Bandit scans Python files for common security issues - [link](https://github.com/PyCQA/bandit)
-  GoSec static analysis of Go code to find security issues - [link](https://github.com/securego/gosec)
-  SpotBugs static analysis tool that detects bugs in Java programs -[link](https://spotbugs.github.io/)
-  Joern code analysis platform for C/C++ code - [link](https://github.com/joernio/joern)
-  Find Sec Bugs a plugin for SpotBugs that focuses specifically on security vulnerabilities for Java code -[link](https://find-sec-bugs.github.io/)
-  Brakeman static analysis security tool specifically designed for Ruby on Rails applications - [link](https://github.com/presidentbeef/brakeman)
-  HoruSec security tool that performs static analysis to find vulnerabilities in source code - [link](https://github.com/ZupIT/horusec)
-  Sast Scan static application security testing (SAST) tool that scans code for security vulnerabilities - [link](https://github.com/ShiftLeftSecurity/sast-scan)
-  cnspec - assesses your entire infrastructure's security and compliance. It finds vulnerabilities and misconfigurations across public and private cloud environments, Kubernetes clusters, containers, container registries, servers, endpoints, SaaS products, infrastructure as code, APIs, and more. [link](https://github.com/mondoohq/cnspec)
-  cnquery - is a cloud-native tool for querying your entire infrastructure. Built upon Mondoo's security data fabric, it answers thousands of questions about your infrastructure and integrates with over 850 resources across cloud accounts, Kubernetes, containers, services, VMs, APIs, and more. [link](https://github.com/mondoohq/cnquery)
