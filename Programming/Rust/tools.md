# Not The Hidden Wiki

## Learn Rust
-----

-  Criterion: Statistics-driven micro-benchmarking library - [link](https://docs.rs/criterion/latest/criterion/)
-  cargo-fuzz: Cargo subcommand for fuzzing with libFuzzer - [link](https://github.com/rust-fuzz/cargo-fuzz)
-  afl.rs: American fuzzy lop (AFL) is a popular, effective, and modern fuzz testing tool - [link](https://github.com/rust-fuzz/afl.rs)
-  quickcheck: Property based testing with shrinking - [link](https://docs.rs/quickcheck/1.0.3/quickcheck/)
-  proptest: Hypothesis-like property testing for Rust - [link](https://github.com/proptest-rs/proptest)
-  cargo-mutants: Mutation testing - [link](https://github.com/sourcefrog/cargo-mutants)
-  mutagen: Mutation testing - [link](https://github.com/llogiq/mutagen)
-  cargo-tarpaulin: Tool to determine code coverage achieved via tests - [link](https://github.com/xd009642/tarpaulin)
-  cargo-msrv: This crate can assist you in finding the Minimum Supported Rust Version for a crate. - [link](https://github.com/foresterre/cargo-msrv)
-  miri: Miri is an Undefined Behavior detection tool - [link](https://github.com/rust-lang/miri)
-  cargo-hack: Cargo subcommand to provide various options useful for testing and continuous integration - [link](https://github.com/taiki-e/cargo-hack)
-  loom: Loom is a tool for testing concurrent programs - [link](https://docs.rs/loom/latest/loom/)
-  cargo-llvm-cov: Cargo subcommand to easily use LLVM source-based code coverage - [link](https://github.com/taiki-e/cargo-llvm-cov)
-  rustfmt: A tool for formatting Rust code according to style guidelines. - [link](https://github.com/rust-lang/rustfmt)
-  clippy: A collection of lints to catch common mistakes - [link](https://github.com/rust-lang/rust-clippy)
-  cargo doc: A collection of lints to catch common mistakes - [link](https://doc.rust-lang.org/cargo/commands/cargo-doc.html)
-  llvm-mca: LLVM Machine Code Analyzer - [link](https://llvm.org/docs/CommandGuide/llvm-mca.html)
-  llmv-dwarfdump: dump and verify DWARF debug information - [link](https://llvm.org/docs/CommandGuide/llvm-dwarfdump.html)
-  OSACA: Open Source Architecture Code Analyzer - [link](https://github.com/RRZE-HPC/OSACA)
-  flamegraph: flamegraphs for Rust projects and everything else - [link](https://github.com/flamegraph-rs/flamegraph)
-  inferno: Rust port of FlameGraph - [link](https://github.com/jonhoo/inferno)
-  wasm-pack: Wasm workflow tool - [link](https://github.com/rustwasm/wasm-pack)
-  hypeprfine: A command-line benchmarking tool - [link](https://github.com/sharkdp/hyperfine)
-  rust-analyzer: A Rust compiler front-end for IDEs - [link](https://github.com/rust-lang/rust-analyzer)
-  cargo-machete: Cargo tool that detects unused dependencies - [link](https://github.com/bnjbvr/cargo-machete)
-  cargo-audit: Audit your dependencies for crates with security vulnerabilities reported to the
[RustSec Advisory Database](https://github.com/RustSec/advisory-db/) - [link](https://github.com/RustSec/rustsec/tree/main/cargo-audit)
-  tokio-console: a debugger for async rust - [link](https://github.com/tokio-rs/console)
