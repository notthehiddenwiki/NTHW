# Not The Hidden Wiki

## Learn PHP
-----

1. Laravel - one of the most popular and modern PHP frameworks making development easy - [link](https://laravel.com)
2. PHP Coding Standards Fixer (PHP CS Fixer) - helps to automatically align PHP codebase with PSR coding standards - [link](https://github.com/PHP-CS-Fixer/PHP-CS-Fixer)
3. PHPStan - helps finding errors in PHP code without running it making it a little bit closer to compiled languages - [link](https://phpstan.org)
4. PHPUnit - practically the most popular framework for unit testing in PHP - [link](https://phpunit.de)
5. Xdebug - powerful debugging extension for PHP - [link](https://xdebug.org)
