# Not The Hidden Wiki

## Learn PHP
-----

-  Laravel - one of the most popular and modern PHP frameworks making rapid development easy - [link](https://laravel.com)
-  PHP Coding Standards Fixer (PHP CS Fixer) - helps to automatically align PHP codebase with PSR coding standards - [link](https://github.com/PHP-CS-Fixer/PHP-CS-Fixer)
-  PHPStan - helps finding errors in PHP code without running it making it a little bit closer to compiled languages - [link](https://phpstan.org)
-  PHPUnit - practically the most popular framework for unit testing in PHP - [link](https://phpunit.de)
-  Symfony - one of the most popular frameworks for PHP suited for more complex enterprise-grade applications - [link](https://symfony.com)
-  Xdebug - powerful debugging extension for PHP - [link](https://xdebug.org)
