## Networking tools
-----

1. EVE-NG - alternative solution to GNS3: powerful networking emulator with multi-vendor support - [link](https://www.eve-ng.net)
2. GNS3 - Powerful tool for building virtualized networking labs - [link](https://www.gns3.com)
3. Packet Tracer - software for basic network simulation - [link](https://www.netacad.com/cisco-packet-tracer)
4. Wireshark - network traffic analyzer - [link](https://www.wireshark.org)
